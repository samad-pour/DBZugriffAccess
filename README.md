# DBZugriffAccess

Ein Visual-Studio-Projekt zur Umsetzung eines Datenbankzugriffs auf eine Microsoft-Access-Datenbank.

## Beschreibung

Das Projekt **DBZugriffAccess** beschäftigt sich mit der Verbindung zwischen einer .NET-Anwendung und einer Microsoft-Access-Datenbank. Im Mittelpunkt stehen die Grundlagen des Datenbankzugriffs sowie das Lesen und Verarbeiten von Daten innerhalb einer Anwendung.

## Funktionen

- Verbindung zu einer Microsoft-Access-Datenbank
- Zugriff auf gespeicherte Daten
- Ausführung von Datenbankabfragen
- Verarbeitung von Datenbankergebnissen
- Grundlagen der Datenbankkommunikation

## Technologien

- Microsoft Visual Studio
- .NET
- Microsoft Access

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/DBZugriffAccess.git
   ```

2. Die Datei `DBZugriffAccess.sln` in Visual Studio öffnen.
3. Falls erforderlich, den Pfad zur Access-Datenbank in der Anwendung anpassen.
4. Das Projekt erstellen.
5. Die Anwendung mit `F5` starten.
